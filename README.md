# WebGL 3D Earth

WebGL 1.0을 이용하여 구현한 3D 지구 모델입니다.

컴퓨터 그래픽스 수업에서 학습한 정점 및 삼각형 메시 구성, 기하학적 변환, 텍스처 매핑, 조명 계산 등을 직접 적용해 보는 것을 목표로 개발했습니다.

기본적인 지구의 자전과 낮·밤 변화 외에도 구름, 대기층, 야간 도시 불빛을 구현했으며, 별도의 고도 확인 모드에서 육지와 해저의 상대적인 높낮이를 확인할 수 있습니다.

## 1. 개발 환경

- Language: JavaScript, HTML, CSS, GLSL ES
- Graphics API: WebGL 1.0
- Development Tool: Visual Studio Code
- Data Processing: Python
- Execution: Web Browser

Three.js와 같은 별도의 3D 엔진을 사용하지 않고 WebGL API를 이용하여 렌더링 과정을 구현했습니다.

## 2. 주요 기능

### 3D 지구 모델링
- 위도와 경도를 기준으로 구체의 정점 좌표 생성
- 삼각형 메시 및 정점 버퍼 구성
- 모델·뷰·투영 행렬을 이용한 좌표 변환
- 마우스 입력을 통한 카메라 회전과 확대·축소

### 텍스처 및 조명
- 지구 표면 텍스처 매핑
- 법선 벡터와 광원 방향을 이용한 낮·밤 계산
- Lambert 확산 반사 및 Blinn-Phong 정반사 적용
- 해양 반사광과 낮·밤 경계 표현

### 추가 시각 효과
- 구름 텍스처 및 구름 그림자
- 지구 가장자리의 대기층 표현
- 도시 위치와 인구 규모를 기반으로 생성한 야간 불빛
- 별 배경 및 지구 표면 색상 보정

### 고도 확인 모드
- 상대 고도 및 수심 데이터를 이용한 정점 변형
- 육지·해양 마스크를 이용한 지형 구분
- 높이 강조 배율 조절(0×~24×)
- 동일한 관측 방향에서 정점 변형 전후 비교
- 고도와 수심에 따른 색상 구분

## 3. 실행 방법

프로젝트를 실행하려면 로컬 HTTP 서버가 필요합니다.

저장소를 다운로드하거나 Clone한 뒤, 프로젝트 최상위 폴더에서 터미널을 실행합니다.

**Python 3가 설치된 환경**

`python3 -m http.server 9715`

서버를 실행한 후 브라우저에서 다음 주소로 접속합니다.

`http://127.0.0.1:9715/index.html`

서버 종료는 터미널에서 `Ctrl + C`를 누르면 됩니다.

macOS에서는 프로젝트에 포함된 `START_MAC.command`를 이용해 서버를 실행할 수도 있습니다.

실행에 필요한 텍스처 이미지와 바이너리 데이터는 `assets` 폴더에 포함되어 있습니다. 별도의 Python 패키지를 설치하지 않아도 기본 프로그램을 실행할 수 있습니다.

## 4. 조작 방법

| 입력 | 기능 |
|---|---|
| 마우스 드래그 | 관측 방향 변경 |
| 마우스 휠 | 확대 / 축소 |
| 마우스 더블 클릭 | 카메라 위치 초기화 |
| Space | 자전 일시 정지 / 재개 |
| R | 초기 상태 복원 |
| H | 기본 관측 / 고도 확인 모드 전환 |
| D / N | 주간 / 야간 관측 방향 |
| C | 구름 표시 전환 |
| L | 주요 도시 불빛 표시 전환 |
| B | 지역별 도시 불빛 표시 전환 |
| G | 지구 표면 색상 보정 전환 |
| [ / ] | 색상 채도 조절 |

고도 확인 모드에서는 슬라이더로 높이 강조 배율을 조절할 수 있습니다.

- `+ / -`: 강조 배율 변경
- `0× / 현재 배율 비교`: 정점 변형 전후 비교
- `Esc`: 기본 관측 모드로 복귀

## 5. 프로젝트 구조

**프로그램 파일**
- `index.html` — 화면 구성 및 사용자 인터페이스
- `style.css` — 화면 스타일
- `main.js` — WebGL 초기화, 메시 생성, 셰이더, 렌더링 및 사용자 입력 처리
- `START_MAC.command` — macOS 로컬 서버 실행 스크립트

**assets/**
- `earth_day.jpg` — 지구 표면 텍스처
- `earth_clouds.png` — 구름 텍스처
- `earth_elevation.png` — 상대 고도 데이터
- `bathymetry_proxy.png` — 상대 수심 데이터
- `land_mask.png` — 육지·해양 마스크
- `terrain_relief.jpg` — 지형 색상 표현용 이미지
- `city_lights.bin` — 주요 도시 발광점 데이터
- `regional_lights.bin` — 지역별 발광점 데이터

**tools/**
- `generate_terrain.py` — 지형 데이터 생성
- `generate_clouds.py` — 구름 텍스처 생성
- `build_city_data.py` — 도시 데이터 구성
- `build_lights.py` — 주요 도시 발광점 생성
- `build_regional_lights.py` — 지역별 발광점 생성

`tools` 폴더의 Python 파일은 데이터 생성 및 전처리를 위한 코드이며, 생성된 데이터는 `assets` 폴더에 저장되어 있습니다.

## 6. 구현 시 고려한 사항

### 지형 데이터

고도 확인 모드에서는 공개 지형도와 육지·해양 마스크를 활용하여 상대 고도 및 수심 데이터를 구성했습니다.

초기에는 색상값만으로 육지와 해양을 구분하면서 일부 대륙이 해저처럼 표현되는 문제가 있었습니다. 이를 수정하기 위해 별도의 마스크를 적용하고, 해안선 주변의 높이 변화가 급격하지 않도록 처리했습니다.

현재 사용한 데이터는 실제 해발고도와 수심을 미터 단위로 나타내는 수치 DEM이 아닌 시각화용 근사 데이터입니다.

### 야간 도시 불빛

도시 위치와 인구 규모를 바탕으로 발광점을 생성하고, 이를 바이너리 파일에 저장했습니다.

실행 시 `Float32Array`로 데이터를 읽어 WebGL 버퍼에 전달하며, 태양광 방향에 따라 야간 영역에서만 발광점이 표시되도록 처리했습니다.

도시 불빛은 실제 위성 관측값이 아닌 도시 분포를 참고해 생성한 시각적 근사 데이터입니다.

## 7. 프로젝트 정리

이번 프로젝트에서는 구체를 생성하는 과정부터 텍스처, 기하학적 변환, 조명, 애니메이션을 하나의 WebGL 프로그램에 적용했습니다.

이후 지형 데이터와 도시 발광점 데이터를 추가하면서 렌더링에 필요한 데이터 생성 및 전처리 과정도 함께 다뤘습니다.

구현 과정에서 발생한 지형 분류 오류와 시각적 표현 문제를 수정하며, 정점 데이터와 셰이더의 계산 결과가 실제 화면에 어떻게 반영되는지 확인할 수 있었습니다.
