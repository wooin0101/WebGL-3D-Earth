# 지구 3D 모델 — 고도 확인 오류 수정 버전

## 실행
VSCode에서 이 폴더를 열고:

```bash
python3 -m http.server 9762
```

브라우저에서 `http://127.0.0.1:9762/index.html?v=terrain-coast-fix-v2` 접속.

새 포트와 URL을 사용하는 이유: 기존 프로젝트를 같은 `localhost` 주소에서 실행했을 때 오래된 `main.js`와 고도·수심 이미지가 재사용되는 문제를 방지합니다.

## 주요 수정
- 육지·바다 기준을 RGB/파란색이 아닌 GSHHS 육지/해양 마스크로 고정
- **3D 정점 변형에도 마스크 적용** (이전에는 색상 셰이더에만 적용됨)
- 내륙 호수는 깊은 바다로 분류하지 않음
- 해안에 가까운 수심값을 부드럽게 감소시켜 거친 절벽 완화
- 이미지와 JS 캐시를 새 버전으로 분리
- 기존 야간 도시 불빛 점의 개수·크기·밝기, 구름과 기본 지구 시각 효과 보존

## 조작
- 드래그: 회전
- 휠: 확대/축소
- H 또는 고도 확인 버튼: 모드 전환
- 슬라이더: 높이 강조 0~24×
- 0× / 현재 배율 비교 버튼: 정점 변형 비교

## 데이터 주의
이 버전은 공개 지형도의 표현과 위·경도 기반 근사 고도·수심을 결합합니다. 해수면 기준 미터 단위의 ETOPO 수치 DEM이 아닙니다.
